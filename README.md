## 📸 About the Project
CampusForm is a student admission registration form designed for SADC Eluru. It provides a structured way to collect student information including personal details, academic background, and contact information — all through a clean and easy-to-use web form.

## ✨ Features
- 📋 Structured multi-field registration form
- 👤 Collects personal details (name, DOB, gender, etc.)
- 📚 Academic information fields (previous school, marks, etc.)
- 📞 Contact details section
- ✅ Form validation to ensure required fields are filled
- 🎨 Clean, professional UI suitable for institutional use
